# 주제카드 — [G2] 마케팅 개인화 — 모두에게 보내는 홍보는 아무에게도 닿지 않는다

> `[FT]` 그룹: **G · 운영(업계)** · 영역: B2B 마케팅·콘텐츠 · 난이도: 보통 · ⚠ **변형 카드**: 지역 대신 **마케팅 시나리오**를 고른다 (지역을 붙이면 기존 카드의 후보표를 재활용할 수 있다)
> ★ 대상을 정해주지 않는다. 시나리오와 특징만 주고 **참가자가 고른다.**
> `[FT]` 참여자 수요 근거: 관광업계 업무효율 선택 13명 중 마케팅 축. 팀9(광고홍보 — 획일적 지역 홍보 문제의식), 팀11(SNS·UGC 마이닝으로 잠재 자원 발굴 관심), 관광마케팅 직무 지망 개인 참가자. 2026-08 확정 명단 기준.

## 1. 문제 중심 주제(이슈)
*지역과 사업자의 홍보는 대부분 '모두에게 같은 메시지'다. 그런데 방문·검색·소비 데이터를 보면 오는 사람은 연령·국적·취향별로 뚜렷이 다르다. 데이터로 타깃을 나누고, 타깃마다 다른 콘텐츠를 만들 수 있다면 — 지금까지 예산과 감으로 하던 홍보를 근거와 자동 생성으로 바꿀 수 있는 자리다.*

## 2. 대상 사용자/페르소나
홍보 예산은 적은데 "누구에게 뭘 보여줘야 할지" 근거가 없는 지역 관광재단·지자체 담당자. / 인스타 계정은 있는데 올릴 콘텐츠를 못 만드는 소상공인·축제 사무국.

## 3. 검증 전 가설
같은 지역이라도 방문자 세그먼트(연령·국적·소비 패턴)별로 반응할 콘텐츠가 다를 수 있다. 데이터로 세그먼트를 나누고 세그먼트별 콘텐츠를 자동 생성하면, 획일적 홍보보다 도달·전환이 나아질 가능성이 있다.

## 4. ★ 후보 시나리오 선택 (참가자가 고른다)
마케팅 '의뢰인'을 먼저 고르고, 대상 지역·상품은 팀이 붙인다. 기존 카드(A1 저활용, C4 특산물, D4 축제 등)의 후보 지역을 의뢰인의 지역으로 재활용해도 좋다.

| 시나리오(의뢰인) | 마케팅 과제 | 타깃 근거 데이터 | 난이도 |
|---|---|---|---|
| 지역 관광재단·지자체 | 방문 세그먼트별 시즌 캠페인 기획 | 데이터랩 방문 추이·연령 다양성·외래객 국가별 | 보통 |
| 저활용 관광지(A1형 지역) | "찾는 사람은 있는데 안 오는" 전환 콘텐츠 | 데이터랩 검색·방문 갭, TourAPI 자원 정보 | 보통 |
| 특산물·로컬브랜드(C4형) | 상품 스토리 콘텐츠·상세페이지 | 6차산업 인증 정보, TourAPI 체험·쇼핑 | 쉬움 |
| 축제 사무국(D4형) | 축제 전 홍보·후 재방문 유도 콘텐츠 | 데이터랩 방문 추이(축제 전후), 행사 정보 | 보통 |

> **선택 가이드**: **타깃 근거 데이터가 이미 있는 시나리오**부터 본다. 세그먼트를 못 나누면 이 카드는 그냥 '콘텐츠 만들기'가 되어 버린다 — 반드시 데이터→타깃→콘텐츠 순서를 지킨다.
> **읽는 법**: 연령·소비·국제 다양성 지수가 높다 = 오는 사람이 다양하다 = **하나의 메시지로는 부족하다**는 단서다. 반대로 다양성이 낮으면 '안 오는 세그먼트를 새로 부르는' 캠페인이 과제가 된다.
> **검증 시(2단계)**: 고른 지역의 데이터랩 지표(연령별 방문·국가별 외래객·소비 업종)를 라이브로 받아 세그먼트 2~3개를 실제로 나눠본다.

## 5. 확인하고 싶은 단서 (시그니처)
같은 지역 안에서 세그먼트별 방문·소비 패턴 차이가 뚜렷하고(연령·국적·업종), 현재 홍보물은 단일 메시지라면 → 개인화 마케팅의 개선 여지 근거.

## 6. 예상 아웃풋 이미지
지역·상품을 넣으면 데이터에서 타깃 세그먼트 2~3개를 뽑고, 세그먼트별 홍보 카피·이미지 컨셉·채널 제안을 카드로 생성하는 화면.

## 7. 추천 MVP
대상 지역·상품 선택 → 데이터랩 지표로 세그먼트 도출 → 세그먼트별 홍보 콘텐츠 자동 생성 → 발표용 캠페인 시안 3종.

### 확장 레이어 (FT 차등 제공)
- **막힐 때 힌트**: 세그먼트가 안 나뉘면 '연령(2030 vs 5060)' 하나만 갈라도 된다. 콘텐츠는 카피 3줄 + 해시태그 + 이미지 컨셉 설명이면 데모로 충분하다.
- **추가 과제**: SNS·UGC 신호로 뜨는 소재를 조기 발굴해 콘텐츠에 반영(팀11 관심 각도) / 국가별 언어·문화 코드에 맞춘 다국어 버전 / 캠페인 성과 가설(도달·전환)을 수치로 설계.
- **접근 방식 힌트**(데이터 본 뒤): 세그먼트 캠페인 생성기 / 상세페이지 빌더 / 시즌 콘텐츠 캘린더 중 택1.
- **팀 작성 칸(빈칸 문장)**: "우리 의뢰인 __(사업자/지역)의 방문자는 __(데이터)에서 __(세그먼트)로 갈린다. 지금 홍보는 __라서 __(세그먼트)에 닿지 않는다. 우리는 __를 자동 생성한다."
