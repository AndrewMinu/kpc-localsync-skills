# 심사위원 예상 질문 준비

> `pitch-rehearse` ④단계의 상세 참고 문서.

## 거의 항상 나오는 질문

| 질문 | 준비할 답의 뼈대 |
|---|---|
| **"이거 진짜 되는 거예요?"** | 지금 되는 것 / 목업인 것 / 실서비스에 필요한 것을 **솔직히 구분해서** 말한다. 숨기면 걸린다. |
| **"데이터 근거가 뭐예요?"** | 출처·지표·수치를 정확히. *"관광공사 수요강도 지수, 통영 숙박비중 87.9 vs 소비 65.3"* |
| **"기존에 있는 서비스 아니에요?"** | 뭐가 다른지 **한 문장**. 없으면 지금 만든다. |
| **"왜 이 지역이에요?"** | 데이터로 답한다. "관심 있어서"는 감점. |
| **"누가 돈을 내요?"** | 지자체 / 관광공사 / 사업자 중 누구에게 무슨 가치인지. |
| **"이 숫자, 상대 지수인데 절대값처럼 말한 거 아니에요?"** | ⚠**우리 데이터의 약점을 심사위원이 먼저 짚을 수 있다.** 지수는 지역 간 비교용임을 알고 있다고 말한다. |

## 우리 프로젝트만의 질문 — 팀이 찾는다

*"우리 발표에서 제일 약한 데가 어디예요? 제가 심사위원이면 거기를 물어볼 텐데."*

**팀이 직접 3개를 뽑고 답을 만든다.** AI가 대신 뽑아주지 않는다 — 자기 약점은 자기가 제일 잘 안다.

## 답변 3원칙

1. **모르면 모른다고 한다.** *"그건 확인 못 했습니다. 다음 단계로 보고 있습니다."* — 아는 척하다 걸리는 게 최악이다.
2. **한계를 먼저 말해버린다.** *"지금은 데이터를 미리 받아 넣었고, 실서비스에선 서버가 매일 갱신합니다."* → 판단할 줄 아는 팀이라는 신호.
3. **30초 안에 끝낸다.** 길어지면 방어처럼 들린다.
