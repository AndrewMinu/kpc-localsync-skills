# 로컬 싱크 — 부트캠프 스킬

2026 미래형 관광인재 양성교육 부트캠프 (로컬 싱크)

## 1. 먼저 이것부터 (설치 전에)

Codex를 열고 이 한 문장만 던지세요.

```
강릉 1박2일 코스 짜줘
```

조건은 아무것도 주지 마세요. 나온 결과는 **그대로 두세요.** 곧 씁니다.

## 2. 설치

```bash
npx skills@latest add AndrewMINU/kpc-bootcamp -a codex -g -y
```

## 3. 시작

```
$bootcamp-start
```

여기서부터는 안내해주는 대로 따라가면 됩니다. 헷갈릴 때 언제든 `$bootcamp-start`를 다시 부르면
지금 어디까지 왔고 다음이 뭔지 알려줍니다.
